api/ – Handles API endpoints and AJAX requests.
assets/ – Stores CSS, JavaScript, images, icons, fonts, and other static files.
auth/ – Manages user authentication, login, logout, and password recovery.
classes/ – Contains reusable PHP classes and custom objects.
config/ – Stores database connections, application settings, and configuration files.
controllers/ – Processes user requests and controls the application's business logic.

database/ – Stores all database-related files.
        backups/ – Database backup files.
        migrations/ – Database schema changes and updates.
        seeders/ – Sample or default database records.
        sql/ – SQL scripts for creating or importing the database.

docs/ – Contains project documentation, manuals, and technical documents.
helpers/ – Stores reusable helper functions used throughout the system.
includes/ – Contains reusable PHP files such as headers, footers, navigation bars, and common components.
logs/ – Stores system logs, error logs, and debugging information.
middleware/ – Checks authentication, authorization, and user permissions before allowing access to pages.
models/ – Handles database operations such as creating, retrieving, updating, and deleting data (CRUD).
public/ – Contains publicly accessible files, including the main index.php entry point.
reports/ – Stores generated financial reports and report templates.
routes/ – Defines application URLs and maps them to the appropriate controllers.
services/ – Contains business services and complex application logic shared across modules.
storage/ – Stores generated files, temporary files, cached files, and other system data.
templates/ – Contains reusable page templates for generating consistent layouts.
tests/ – Stores unit tests and integration tests to verify system functionality.
uploads/ – Stores user-uploaded files such as receipts, invoices, documents, and profile pictures.
vendor/ – Contains third-party libraries and Composer dependencies.

views/ – Contains all user interface pages.
        layouts/ – Master page layouts shared across the system.
        partials/ – Reusable page sections such as headers, sidebars, and footers.
        errors/ – Custom error pages (e.g., 404 and 500).
        shared/ – interface pages.
        
widgets/ – Contains reusable dashboard widgets, cards, charts, and other UI components.
